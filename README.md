# 📋 Todo Master (정적 웹 기반 투두앱)

의존성 설치나 백엔드 서버 없이 브라우저에서 즉시 실행 가능한 정적 빌드(Static Single-Page Application) 할 일 관리 앱입니다.

## ✨ 주요 기능
- **할 일 CRUD**: 생성, 상태 토글(완료/미완료), 수정(인라인 프롬프트), 삭제
- **카테고리 & 우선순위**: 개인, 업무, 공부 등 카테고리 태깅 및 3단계 우선순위(높음, 보통, 낮음)
- **마감일 관리**: 마감일 설정 시 D-Day 계산 및 임박/지남 뱃지 표시
- **필터 & 검색 & 정렬**:
  - 상태별 필터 (전체 / 진행 중 / 완료됨)
  - 카테고리별 필터
  - 실시간 키워드 검색
  - 정렬 (최신순 / 오래된순 / 마감일순 / 우선순위순)
- **진행률 통계**: 전체/진행/완료 수치 및 프로그레스 바 실시간 업데이트
- **로컬 스토리지 자동 저장**: 브라우저를 닫아도 데이터 유지
- **다크/라이트 모드**: 사용자의 선호 테마 지원 및 설정 유지
- **데이터 백업 및 복원**: JSON 파일 내보내기/가져오기 지원

---

## 🚀 실행 방법

### 방법 1. 브라우저에서 바로 열기
별도의 웹 서버 설치 없이 `index.html` 파일을 더블 클릭하여 기본 웹 브라우저에서 바로 실행할 수 있습니다.

### 방법 2. 로컬 웹 서버로 열기 (추천)
Node.js가 설치되어 있는 경우:
```bash
# npx serve 사용
npx serve .
```
또는 Python이 설치되어 있는 경우:
```bash
python3 -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속

## 🌐 정적 배포 (Static Hosting)
빌드 과정 없이 HTML/CSS/JS 파일 그대로 다음 무료 호스팅에 올릴 수 있습니다:
- **GitHub Pages**: 레포지토리 Settings -> Pages -> main 브랜치 지정
- **Vercel / Netlify**: 루트 디렉토리를 그대로 정적 프로젝트로 연결
- **Cloudflare Pages**: 소스 연결 후 빌드 명령어 없이 배포
